# Australian English

Use these conventions when Australian English applies. Preserve proper nouns, brands, exact titles, quotations and requested house style.

- Use `-ise` and `-isation`: organise, recognise, standardise.
- Use `-our`: colour, favour, behaviour.
- Use `-re`: centre, metre, fibre.
- Use `-yse`: analyse, paralyse.
- Use `-ence` for the nouns defence, offence and licence; use `license` as a verb.
- Distinguish `practice` as a noun from `practise` as a verb.
- Double the final `l`: travelling, modelling, labelled and cancelled.
- Use `-ogue`: catalogue and dialogue.
- Prefer grey, mum and aluminium.
- Use `program` for software and `programme` only for events or broadcasts.
- Write new headings in sentence case.
- Write full dates as `10 June 2026` unless another format is supplied or requested.

Do not treat suffixes as blind search-and-replace rules. Many valid words end in `-or` or `-er`; change only genuine spelling variants.
