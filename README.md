# writing-style

A Claude Code and Codex skill that enforces Australian English and a direct, human voice without changing the substance of the writing.

## What it does

- **Australian English** in full: -ise, -our, -re, -yse, doubled L, practise/practice, sentence-case headings and no Oxford comma
- **Bans the AI-tell word family when used as filler**: leverage, seamless, delve, "I hope this email finds you well", "excited to announce" and the rest (the full list lives in SKILL.md), including nearest-synonym swaps
- **Bans AI sentence structures**, which matter more than word choice: em dashes, the rule-of-three default, "not X, but Y" contrasts, rhetorical question-answer pairs, engagement bait, hashtag blocks and neat-bow endings
- **Bans the assistant-commentary frame**: the conversational wrapper around a deliverable, including effort narration ("the analysis I promised"), hand-over openers in any person ("here's the map", "below is the analysis"), meta-closers and offers to continue ("that's my read", "want me to go deeper?") and reader-flattery, while keeping first-person opinions and plain statements of what was done that are the content
- **Replaces vague intensity with supplied specifics**: "40% faster", not "significantly faster"
- **A voice section** that defines how the writing should sound: short messages, blunt opinions backed by numbers, plain subject lines and warmth through specifics rather than gush
- **Content fidelity**: preserves facts, uncertainty, commitments and required terminology instead of inventing stronger claims while rewriting
- **A self-check pass** before anything is delivered

Works on anything a human will read (the authoritative scope list lives in SKILL.md). Particularly good at cleaning up text generated by other LLMs.

## How it triggers

The skill only runs when you ask for it:

- `/writing-style` in Claude Code
- `$writing-style` in Codex
- "use the writing-style skill" or "apply your writing rules" in a prompt

It deliberately does not fire on every prose task. Auto-triggering loads the whole guide into context on anything that looks like writing, which burns tokens fast. Claude Code uses the `description` field in SKILL.md to decide when to load it. Codex also sets `policy.allow_implicit_invocation` to `false` in `agents/openai.yaml`.

The invocation name comes from the folder you clone into. Keep it as `writing-style` unless you also update the skill name and Codex prompt metadata.

## Customising

The runtime guide is `SKILL.md`, with optional Codex interface metadata in `agents/openai.yaml`. Fork the repository and edit them to suit:

- **The Voice section is tuned to the author.** Its greeting habits, bluntness and colloquialisms are one person's; replace them with your own. Mine a sample of your sent emails for patterns; that's how this one was built.
- Swap Australian English for British English (minor changes)
- Add or remove banned words and constructions
- Put the Oxford comma back if you must

## Evals

The eval set is committed at [eval/PROMPTS.md](eval/PROMPTS.md): writing tasks across casual and formal registers, fidelity tests, explicit style overrides and a marking checklist. Preserve raw model output, use fresh contexts and separate generation from marking. Scored runs are committed under [eval/](eval/) so the claims are checkable.

Latest full run ([eval/results-2026-06b.md](eval/results-2026-06b.md)): every piece passed every applicable checklist row with the skill loaded, and the no-skill baseline failed four of seven tasks. The unguided model has cleaned up since the first run (no emoji or hashtag blocks this time); what still separates the two is invented numbers, triad stacking, stray em dashes and banned words. The earlier run is kept at [eval/results-2026-06.md](eval/results-2026-06.md).

A targeted run for the assistant-commentary-frame rule ([eval/results-2026-06c.md](eval/results-2026-06c.md)) added task 8, an analysis writeup that tempts the frame. These June results predate the current fidelity and precedence rules and remain historical evidence, not a current full-suite result.
