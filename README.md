# writing-style

A Claude Code skill that enforces Australian English, bans AI-tell words and structures, and writes in a direct, human voice.

## What it does

- **Australian English** in full: -ise, -our, -re, -yse, doubled L, practise/practice, sentence-case headings and no Oxford comma
- **Bans 60+ AI-tell words and phrases**: leverage, seamless, delve, "I hope this email finds you well", "excited to announce" and the rest of the family
- **Bans AI sentence structures**, which matter more than word choice: em dashes, rule-of-three lists, "not X, but Y" contrasts, rhetorical question-answer pairs, engagement bait, hashtag blocks and neat-bow endings
- **Replaces vague intensity with specifics**: "40% faster", not "significantly faster"
- **A voice section** that defines how the writing should sound: short messages, blunt opinions backed by numbers, plain subject lines and warmth through specifics rather than gush
- **A self-check pass** before anything is delivered

Works on emails, Slack messages, blog posts, reports and anything else a human will read. Particularly good at cleaning up text generated by other LLMs.

## Install

```bash
# Clone into your Claude Code skills directory
git clone https://github.com/AdenCJM/writing-style.git ~/.claude/skills/writing-style
```

## How it triggers

The skill only runs when you ask for it:

- `/writing-style` as a slash command
- "use the writing-style skill" or "apply your writing rules" in a prompt

It deliberately does not fire on every prose task. Auto-triggering loads the whole guide into context on anything that looks like writing, which burns tokens fast. If you'd rather have it always on, edit the `description` in the SKILL.md frontmatter to describe prose-writing situations instead of explicit requests, and Claude Code will pick it up automatically.

## Example

**Before (AI-typical):**

> In today's rapidly evolving digital landscape, organisations must leverage cutting-edge technologies to seamlessly navigate the complexities of modern business. It is important to note that a holistic approach to digital transformation can yield extraordinary results.

**After:**

> Most companies buy new tools and change nothing else. The ones getting results rewired how the work happens first. The tool came second.

## Customising

The skill is a single `SKILL.md` file. Fork it and edit to suit:

- **The Voice section is tuned to the author.** Replace it with your own habits: how you greet people, how you sign off, how blunt you are. Mine a sample of your sent emails for patterns; that's how this one was built.
- Swap Australian English for British English (minor changes)
- Add or remove banned words and constructions
- Put the Oxford comma back if you must

## Evals

The eval set is committed at [eval/PROMPTS.md](eval/PROMPTS.md): five tasks (Slack, email, LinkedIn, one-pager, slop rewrite) and a 12-row marking checklist. Run the tasks with and without the skill and mark both sets.

Latest run (June 2026, Claude Code): all five pieces passed every checklist row with the skill loaded, with one allowed triad across the set. The no-skill baseline failed on em dashes, decorative emoji, "I hope you're doing well!" openers, bold lead-in bullets, engagement bait and a hashtag block.
